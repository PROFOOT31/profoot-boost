PROFOOT BOOST — VERSION 01

Contenu :
- Tableau de bord de démonstration
- Générateur de hashtags
- Planificateur local de contenu
- Base PWA pour ajout à l’écran d’accueil iPhone

IMPORTANT :
Les statistiques Instagram affichées par des tirets ne sont pas encore connectées.
Cette version ne génère pas de faux abonnés, vues ou likes et ne demande jamais le mot de passe Instagram.

INSTALLATION :
1. Héberger le contenu de ce dossier sur un hébergement HTTPS.
2. Ouvrir l'adresse HTTPS dans Safari sur iPhone.
3. Appuyer sur Partager > Sur l’écran d’accueil > Ajouter.

Pour connecter les statistiques réelles, il faudra ensuite configurer une application Meta et utiliser l'API Instagram officielle, avec les autorisations appropriées.
